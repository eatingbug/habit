# ADR-0012: 알림은 웹 푸시로 보낸다

- 상태: 채택됨.
- 날짜: 2026-11-04.
- 관계: ADR-0011의 알림을 보내는 수단을 정한다. 기존 PWA의 서비스 워커(`public/sw.js`)를 사용한다.

## 결정

- 알림은 PWA의 웹 푸시로 보낸다. 서버는 오늘이 `pending`인지 확인한 뒤 보낸다.
- 카카오 알림톡은 채택하지 않는다. 딜러사 계약, 비즈니스 채널, 템플릿 검수, 전화번호 수집, 건당 비용이 필요하다. 습관 알림이 정보성 템플릿으로 승인되는지도 확인되지 않았다.
- 카카오 "나에게 보내기" API는 채택하지 않는다. 휴대폰 알림이 울리지 않는다.
- 안드로이드 앱 푸시는 채택하지 않는다. 앱 안의 카카오 로그인이 아직 없고, 스토어 배포가 필요하다.
- 기기 안에서 예약하는 알림은 채택하지 않는다. 다른 기기에서 기록한 날에도 알림이 울려 ADR-0011을 지킬 수 없다.

## 감수하는 것

- iPhone은 홈 화면에 추가한 PWA에서만 알림을 받는다.
- 푸시 구독은 기기와 브라우저마다 따로 있다. 권한을 끄거나 데이터를 지우면 구독이 사라진다.
- 기기의 절전 기능 때문에 알림이 정한 시각보다 늦게 올 수 있다.
