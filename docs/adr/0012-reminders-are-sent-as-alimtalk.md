# ADR-0012: 알림은 알림톡으로 보낸다

- 상태: 채택됨.
- 날짜: 2026-11-04.
- 관계: ADR-0011의 알림을 보내는 수단을 정한다.

## 결정

- 알림은 카카오 비즈니스 채널의 알림톡으로 보낸다. 발송은 카카오 공식 딜러사의 API를 거친다.
- 카카오 "나에게 보내기" API는 채택하지 않는다. 메시지가 사용자의 나와의 채팅에 쌓이고 휴대폰 알림이 울리지 않는다.
- 알림은 정한 시각에 사용자가 알아차려야 의미가 있다. 그래서 무료이고 기존 로그인을 그대로 쓰는 장점보다 알림이 울리는 쪽을 택한다.

## 감수하는 것

- 건당 발송 비용이 든다.
- 사업자 심사를 거친 비즈니스 채널과 템플릿 검수가 필요하다. 템플릿이 반려되면 알림을 보낼 수 없다.
- 알림톡은 전화번호로 보낸다. 그래서 사용자의 전화번호를 받아야 한다.
