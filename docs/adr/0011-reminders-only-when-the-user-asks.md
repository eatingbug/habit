# ADR-0011: 알림은 사용자가 켠 습관에만 보낸다

- 상태: 채택됨.
- 날짜: 2026-11-04.
- 관계: ADR-0002와 SPEC §1108·§1344의 "푸시하지 않는다"에 대한 첫 예외다. CONCEPT §7.4의 알림 무감각 경계를 유지한다.

## 결정

- 시스템의 판단으로 보내는 푸시는 여전히 없다. 채우기 제안과 기록 뒤 문구는 앱 안에만 남는다.
- 알림은 사용자가 켠 습관에 대해 사용자가 정한 시각에만 보낸다.
- 그 시각에 오늘이 `pending`일 때만 보낸다. 활동이나 skip이 이미 있으면 보내지 않는다.
- 알림 시각은 신호와 별도의 항목이다. 신호는 자유 글이라 시각으로 바꿀 수 없다.
- 매일 무조건 보내는 방식은 이미 한 사람에게도 메시지가 가서 알림 무감각을 만든다. 그래서 채택하지 않는다.
