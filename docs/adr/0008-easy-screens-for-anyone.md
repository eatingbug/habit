# ADR-0008: 쉬운 화면의 기준은 누구든 쓰기 쉬운 화면이다

- 상태: 채택됨
- 날짜: 2026-10-14
- 관계: ADR-0007의 "기준은 초등학생도 한눈에 알아볼 명료함이다"를 대체한다. ADR-0007의 나머지 결정은 유지한다.
- 영향 범위: `docs/SPEC.md` §6.0, `design/_tokens.redesign.css`, `design/`, `src/theme/`, `src/components/today/HabitCard.tsx`, `src/components/dashboard/HabitRow.tsx`, `app/_layout.tsx`

## 문제

- 증상: 모바일에서 글자와 UI 요소가 크다.
- 증상: 폰 한 화면에 습관 카드가 3개만 보인다.
- 증상: 웹에서는 화면이 창 폭 전체로 늘어난다.
- 원인: 디자인 값 자체가 크다. 본문 17, 습관 이름 20, 카드 버튼 56, 아이콘 52다.
- 원인: 이 값들은 ADR-0007의 "초등학생도 한눈에 알아볼 명료함" 기준에서 나왔다.
- 원인: 앱에 최대 폭 제한이 없다.

## 결정

- 기준은 누구든 쓰기 쉬운 화면이다.
- 글씨 단계를 줄인다. label, body, title, headline, display, number 순으로 12, 15, 17, 20, 24, 34다.
- 굵기와 줄 높이 비율은 그대로다.
- 최소 터치 영역은 48에서 44로 낮춘다.
- 간격 단계를 토큰으로 둔다. 이번에는 화면 틀과 습관 카드에만 적용한다.
- 웹에서는 콘텐츠를 최대 폭 480으로 제한하고 가운데에 둔다. 최대 폭 밖은 테마 `bg` 색이다.
- 오늘 탭과 홈 탭의 습관 카드를 컴팩트하게 바꾼다. 390×844 화면에 습관 카드 5~6개가 보이게 한다.
- ADR-0007의 나머지 결정은 유지한다. 밝은 색, 상태의 색·아이콘·글자 병기, `?` 툴팁, 또렷한 게임 요소가 그대로다.

## 고른 대안

- 전체를 0.85배로 일괄 축소하는 안은 버렸다. 터치 영역이 44 아래로 내려간다.
- 넓은 화면에 2열 그리드를 두는 안은 버렸다. 모든 화면의 아트보드를 새로 그려야 한다.

## 결과

- 토큰 CSS가 계속 단일 원본이다. 수치는 CSS를 먼저 바꾸고, 아트보드를 다시 빌드하고, RN 토큰을 맞춘다.
- 터치 영역 최소값도 토큰 CSS에 둔다.
- SPEC §6.0의 글씨 단계 표와 터치 영역 규칙은 새 수치로 고친다.
- 글씨 단계와 터치 영역은 토큰 교체 한 번으로 모든 화면에 적용된다. ADR-0007이 금지한 옛 화면과 새 화면의 혼합 배포에 해당하지 않는다.
- 도메인 규칙은 바뀌지 않는다.
