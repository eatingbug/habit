# ADR-0010: 습관 순서는 한 번에 저장한다

- 상태: 채택됨.
- 날짜: 2026-10-27.
- 근거: 이슈 #185와 A안 프로토타입의 사용자 확인.
- 관계: ADR-0005의 서버 단일 원본과 RLS 경계를 유지한다. 저장소에 `reorderHabits(ids)`를 추가한다.
- 기존 메서드의 시그니처는 유지한다. 사용자 ID 인자는 추가하지 않는다.

## 결정

- `habits.sort_order`는 표시 순서만 저장한다. 습관 설계의 일반 저장은 이 컬럼을 쓰지 않는다.
- `reorder_habits` RPC는 요청한 습관의 위치를 하나의 트랜잭션에서 바꾼다.
- 숨겨진 습관은 기존 위치를 유지한다. 순서가 없는 새 습관은 마지막에 표시한다.
- 함수는 호출자의 권한으로 실행한다. 다른 사용자의 습관이 포함되면 전체 요청을 거부한다.
- 습관별 저장 요청을 반복하는 방법은 중간 실패로 일부만 바뀔 수 있어 채택하지 않는다.
- 전체 습관을 다시 저장하는 방법은 다른 화면의 설계 수정을 덮어쓸 수 있어 채택하지 않는다.
- `method`는 선택적인 실행 방법이다. 기존 `cue`는 변환하거나 분해하지 않는다.
- 마이그레이션을 먼저 적용한 뒤 새 클라이언트를 배포한다.
